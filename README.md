# 光陰慢聊・父母生命故事訪談抽卡遊戲 (Parent Story Cards)

專為成年子女設計的手機優先（Mobile-First）抽卡互動 Web App。讓你在溫馨、輕鬆的圍爐或品茗茶席氣氛中，一邊抽卡談心，一邊錄下父母從童年、青春、出社會打拼、戀愛成家、育兒到熟年智慧的珍貴口述歷史。

👉 **[點此直接在手機/電腦上線體驗 (GitHub Pages)](https://edwardyy1224.github.io/parent-story-cards/)**
*(支援 HTTPS，手機 Safari/Chrome 可直接錄音)*


---

## 🌟 核心功能特色

1. **單一自包含檔案架構（Single-File HTML/CSS/JS）**：
   - 零依賴、免安裝、離線可用。
   - 直接用 Safari、Chrome 雙擊或靜態伺服器打開即可運作。
2. **手機優先設計（Mobile-First & 長輩友善）**：
   - 溫暖宣紙與茶褐色調（高對比度且柔和護眼）。
   - 復古拍立得 3D 翻牌動畫（Card Flip Animation）。
   - 字體放大縮小按鈕（標準 20px / 舒適 24px / 特大 28px），長輩對坐也能看清。
   - 支援左右滑動手勢（Swipe Left / Swipe Right）流暢抽換卡片。
3. **精選六大人生階段（Claude Opus 深度審查 68 道核彈級好題 + 傾聽錦囊）**：
   - 包含【出生與童年】(11題)、【青春求學與入伍】(11題)、【出社會與打拼】(12題)、【戀愛與成家】(11題)、【為人父母育兒】(12題)、【熟年智慧與叮嚀】(11題)。
   - 特別補足「母親女性史（工廠女工、長姊貼補家庭）」、「惜物執念與金錢安全感」、「單親家庭包容性」與震撼催淚的「世紀和解牌（管教心疼與道歉）」。
   - 每一題皆附帶「💡 傾聽引導小錦囊」，指引子女追問當年的聲音、氣味、物價或情感細節。
   - 支援「全部隨機」與各階段膠囊切換，防呆不重複抽取。
4. **內建訪談錄音機（MediaRecorder API）**：
   - 懸浮工具列，大按鈕支援一鍵開始、呼吸紅點指示、秒數計時、暫停與結束保存。
   - 訪談結束後可直接線上試聽，並一鍵下載 `.webm` / `.mp4` 音訊至手機保存（檔名自動以日期與題目命名）。
   - 100% 瀏覽器本機錄音，不依賴任何外部伺服器，安全保密。
5. **自訂題目與收藏清單（LocalStorage）**：
   - 「＋」浮動按鈕可即時輸入私房問題並加入題庫。
   - 「⭐」收藏按鈕可把最感動或長輩想聊的題目加入專屬清單，隨時重抽。

## 🚀 如何在手機上開啟體驗

### 方法 A：電腦本機直接開啟
- 直接在檔案總管中雙擊 `index.html`，即可在任何瀏覽器中體驗完整功能。

### 方法 B：同區域網路透過手機瀏覽（推薦）
在專案目錄下啟動本機簡易 HTTP 伺服器：
```bash
# 在 PowerShell 或終端機中：
cd d:\APP_DEV\parent_story_cards
python -m http.server 8080
```
接著拿出手機，連接相同 Wi-Fi，在手機 Safari 或 Chrome 輸入：
`http://電腦區域網路IP:8080`
即可隨開隨玩！
*(註：手機端使用麥克風錄音時，若使用 Chrome 建議搭配 localhost、HTTPS 或在 Chrome flags 中允許 insecure-origins 進行麥克風錄音；iOS Safari 則支援區域網路與本地網址存取麥克風)*
